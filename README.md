# Psych 755 Project

This is a Quarto manuscript project for Psych 755.

## Author
Rachel Rapier

## Date
July 8, 2026

## Project Structure
- `index.qmd` - Main manuscript file
- `supplemental.qmd` - Supplemental materials
- `references.bib` - Bibliography file
- `_quarto.yml` - Quarto project configuration

## Building the Project

To render the manuscript to HTML:
```bash
quarto render index.qmd --to html
```

To render the manuscript to PDF:
```bash
quarto render index.qmd --to pdf
```

To render the manuscript to Word:
```bash
quarto render index.qmd --to docx
```
